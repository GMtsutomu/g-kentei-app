G検定完全攻略ロードマップ - PWA導入手順
========================================

【フォルダ構成】
このフォルダには、以下のファイルが含まれています。

  top.html                      ← アプリ本体（PWA対応済み）
  manifest.json                 ← PWA設定ファイル
  sw.js                         ← オフライン対応用スクリプト
  icons/icon-192.png            ← アイコン（192×192）
  icons/icon-512.png            ← アイコン（512×512）
  icons/icon-maskable-192.png   ← Android用マスカブルアイコン
  icons/icon-maskable-512.png   ← Android用マスカブルアイコン

これまでに作成した記事HTMLファイル（gkentei-overview-01.html など）も、
このフォルダの直下（top.htmlと同じ階層）に置いてください。

【重要】HTTPSでの公開が必要です
PWAのインストール機能・オフライン対応（Service Worker）は、
仕組み上、以下のいずれかの環境でしか動作しません。

  ・HTTPSで公開されたWebサーバー
  ・localhost（お使いのパソコン上でのテスト時）

file:// で直接ダブルクリックして開いた場合、通常の記事サイトとしては
問題なく閲覧できますが、「ホーム画面に追加」やオフライン閲覧の機能は
動作しませんのでご注意ください。

【スマートフォンでの追加方法】
・Android（Chrome）：
    サイトを開くと画面下部に「ホーム画面に追加」バナーが自動表示されます。
・iPhone（Safari）：
    Safariには自動バナー機能がないため、共有ボタン（□に↑）から
    「ホーム画面に追加」を選んでください。

【記事を追加・更新したときの注意】
新しい記事ファイルを追加した場合、オフラインでもすぐに読めるようにするには
sw.js内の ARTICLE_ASSETS の配列に、追加したファイル名を書き足してください。
（書き足さなくてもオンライン時は問題なく動作し、一度開いた記事は
  自動的にキャッシュされます）

書き足した後は、sw.js冒頭の CACHE_VERSION の数字を1つ増やしてください
（例："v1" → "v2"）。こうすることで、利用者のスマートフォンに残っている
古いキャッシュを確実に入れ替えることができます。
