G検定対策アプリ - PWA導入手順
========================================

【フォルダ構成】
このフォルダには、以下のファイルが含まれています。

  index.html                    ← アプリ本体（PWA対応済み）
  manifest.json                 ← PWA設定ファイル
  sw.js                         ← オフライン対応用スクリプト
  icons/icon-192.png            ← アイコン（192×192）
  icons/icon-512.png            ← アイコン（512×512）
  icons/icon-maskable-192.png   ← Android用マスカブルアイコン
  icons/icon-maskable-512.png   ← Android用マスカブルアイコン
  questions/basic/ch1.js〜ch8.js  ← 基本問題データ（お使いの既存ファイルをここに配置）
  questions/mock/ch1.js〜ch8.js   ← 模擬問題データ（お使いの既存ファイルをここに配置）

★ questions/basic/ と questions/mock/ の中身は、これまで作成してきた
  16個のファイルをこのフォルダ構成のとおりに配置してください
  （このZIPには中身が空のフォルダのみ入っています）。

【重要】HTTPSでの公開が必要です
PWAのインストール機能・オフライン対応（Service Worker）は、
仕組み上、以下のいずれかの環境でしか動作しません。

  ・HTTPSで公開されたWebサーバー
  ・localhost（お使いのパソコン上でのテスト時）

file:// で直接ダブルクリックして開いた場合、通常の問題演習アプリとしては
問題なく利用できますが、「ホーム画面に追加」やオフライン利用の機能は
動作しませんのでご注意ください。

【スマートフォンでの追加方法】
・Android（Chrome）：
    サイトを開くと画面上部に「ホーム画面に追加」バナーが自動表示されます。
・iPhone（Safari）：
    Safariには自動バナー機能がないため、共有ボタン（□に↑）から
    「ホーム画面に追加」を選んでください。

【問題を追加・修正したときの注意】
questions/basic/ch4.js や questions/mock/ch5.js などの中身を更新した場合、
sw.js冒頭の CACHE_VERSION の数字を1つ増やしてください（例："v1" → "v2"）。
こうすることで、利用者のスマートフォンに残っている古い問題データが
確実に新しいものへ入れ替わります。番号を変えないと、オフライン用の
キャッシュが優先され、更新した問題が反映されない場合があります。
